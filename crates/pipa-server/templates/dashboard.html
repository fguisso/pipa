manage sites from the CLI

Deploys and destructive changes (delete, make public) run through the pipa CLI, which confirms sensitive actions on a second device. 

pipa deploy ./dist                 # deploy / update a site
pipa ls                            # list your sites
pipa share <id> --zone public      # change visibility (step-up)
pipa rm <id>                        # delete a site (step-up)
